# Стратегии слухового распознавания

Статический сайт для пилотного исследования стратегий слухового распознавания у музыкантов.

Сайт измеряет:

- анкетные данные участника без ФИО;
- анонимный код участника;
- правильность ответов;
- время реакции;
- количество повторов;
- использование камертона;
- выбранные стратегии после каждого блока;
- ответы про голос и мотивацию к сольфеджио.

## Режимы

- **Полный режим** — около 25–30 минут, включает трезвучия и септаккорды.
- **Короткий режим** — около 15 минут, только трезвучия в аккордовом блоке.

## Файлы

- `index.html` — страница сайта.
- `styles.css` — оформление.
- `app.js` — логика заданий, звук, таймеры, сбор данных.
- `google-apps-script.gs` — код Google Apps Script для автоматической отправки в Google Sheets.
- `README.md` — эта инструкция.

## Как опубликовать сайт на GitHub Pages

1. Создайте новый репозиторий на GitHub, например `solfege-hearing-study`.
2. Загрузите файлы `index.html`, `styles.css`, `app.js`, `google-apps-script.gs`, `README.md`.
3. Откройте настройки репозитория: **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Сохраните настройки.
6. Через 1–3 минуты GitHub покажет ссылку на сайт.

## Как подключить автоматическую отправку в Google Sheets

### 1. Создайте Google Таблицу

Создайте новую Google Таблицу, например `Solfege hearing study responses`.

Скопируйте ID таблицы из адреса. В ссылке вида:

```text
https://docs.google.com/spreadsheets/d/1ABCDEFghijk12345/edit#gid=0
```

ID — это часть между `/d/` и `/edit`:

```text
1ABCDEFghijk12345
```

### 2. Откройте Apps Script

В Google Таблице откройте:

**Расширения → Apps Script**

Удалите стандартный код и вставьте содержимое файла `google-apps-script.gs`.

В начале файла замените:

```javascript
const SPREADSHEET_ID = 'PASTE_SPREADSHEET_ID_HERE';
```

на ID вашей таблицы.

### 3. Подготовьте таблицу

В Apps Script выберите функцию `setup` и нажмите **Run / Выполнить**.

Google попросит разрешения. Разрешите доступ к таблице и Google Drive. Drive нужен, чтобы сохранять полный JSON каждого ответа отдельным файлом, а в таблицу класть ссылку на него.

### 4. Разверните Apps Script как Web App

Нажмите:

**Deploy → New deployment → Web app**

Настройки:

- **Execute as:** Me / Выполнять от моего имени
- **Who has access:** Anyone / Все

Скопируйте Web App URL.

### 5. Вставьте URL в сайт

Откройте `app.js` и найдите строку:

```javascript
const GOOGLE_SHEETS_WEB_APP_URL = '';
```

Вставьте туда URL:

```javascript
const GOOGLE_SHEETS_WEB_APP_URL = 'https://script.google.com/macros/s/.../exec';
```

Сохраните файл и загрузите обновлённый `app.js` на GitHub.

## Как устроен анонимный код

Сайт автоматически создаёт код вида:

```text
SOLF-ME6Q7XYZ-A1B2C3
```

Участник видит этот код в анкете. Его можно оставить или заменить на ваш заранее выданный код, например:

```text
PILOT-001
```

Не собирайте ФИО, телефон, адрес, школу/класс в прямом виде, если это не нужно для исследования.

## Как отправляются данные

На последнем экране участник нажимает **«Отправить в Google Sheets»**.

Сайт отправляет текстовые данные в Apps Script. Apps Script:

1. добавляет строку в лист `responses`;
2. сохраняет полный JSON в Google Drive;
3. кладёт ссылку на JSON-файл в таблицу.

Из-за ограничений браузера запрос отправляется в режиме `no-cors`, поэтому сайт не может прочитать ответ сервера. После теста проверьте, появилась ли строка в таблице.

## Голосовые записи

По умолчанию голосовые записи **не отправляются** в Google Sheets/Drive автоматически, чтобы не перегружать запрос и не терять данные из-за размера файла.

Если участник записывал голосовой ответ, нужно скачать **полный JSON** на последнем экране и передать его исследователю отдельно.

В автоматическую отправку попадает отметка, что голосовые ответы были, но сами аудиоданные заменяются на `null`.

## Рекомендация перед настоящим сбором

Проведите пилот на 3–5 людях:

- проверьте, появились ли строки в Google Sheets;
- проверьте, открываются ли JSON-файлы в Drive;
- измерьте реальное время прохождения;
- уточните формулировки заданий;
- проверьте сайт на телефоне и компьютере.
