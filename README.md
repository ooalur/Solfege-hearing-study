# Рабочий протокол пилотного исследования

## Основной вопрос
Какими стратегиями музыканты пользуются при решении сольфеджийных задач и как эти стратегии могут быть учтены в педагогике сольфеджио?

## Основные блоки
1. Ноты.
2. Мелодические интервалы — отдельный блок; направления сбалансированы 50/50.
3. Гармонические интервалы — отдельный блок.
4. Аккорды.
5. Тембр — отдельный исследовательский блок с флейтой и скрипкой.
6. Внутренний слух.
7. Опыт и мотивация изучения сольфеджио.

## Что фиксируется для каждого слухового задания
Тип задания, тембр, предъявление, направление, конкретные MIDI-высоты, правильный ответ, первый выбор, окончательный выбор, правильность, число повторов, изменение ответа, время от начала звучания и латентность после окончания последнего звучания.

## Тембровый блок
Он остаётся дополнительной, исследовательской частью, а не главным предметом работы. Внутри одного прохождения одинаковый стимул не предъявляется подряд на флейте и скрипке. Количество задач по двум тембрам одинаково; распределение стимулов контрбалансируется условием A/B.

## Интерпретация
Открытые ответы о стратегиях анализируются сначала по описаниям самих участников, затем кодируются с опорой на категории слуховых, зрительных и кинестетических стратегий; допускаются новые категории, возникающие из данных.
