# Стратегии слухового распознавания у музыкантов

Пилотный статический сайт для GitHub Pages. Результаты отправляются в Google Sheets через Google Apps Script.

## Что загружать на GitHub Pages

Загружайте в публичный репозиторий только:

- `index.html`
- `styles.css`
- `app.js`
- `README.md` по желанию

Не загружайте публично `google-apps-script.gs`, если в нём уже вставлены ID таблицы, ID папки Drive или email.

## Настройка Google Sheets

1. Создайте Google Таблицу.
2. Скопируйте ID таблицы из URL между `/d/` и `/edit`.
3. В таблице откройте `Расширения → Apps Script`.
4. Вставьте код из `google-apps-script.gs`.
5. Вставьте ID таблицы в строку:

```js
const SPREADSHEET_ID = 'PASTE_SPREADSHEET_ID_HERE';
```

6. При желании заполните:

```js
const DRIVE_FOLDER_ID = '';
const NOTIFY_EMAIL = '';
```

7. Сохраните скрипт.
8. В выпадающем списке функций выберите `setup` и нажмите `Выполнить`.
9. Разрешите доступы.
10. Разверните скрипт как Web App:
   - Deploy / Развернуть → New deployment / Новое развертывание
   - Type / Тип: Web app / Веб-приложение
   - Execute as / Выполнять от имени: Me / Я
   - Who has access / У кого есть доступ: Anyone / Все
11. Скопируйте Web App URL.
12. Вставьте его в `app.js`:

```js
const GOOGLE_SHEETS_WEB_APP_URL = 'https://script.google.com/macros/s/.../exec';
```

## Что сохраняется

В Google Таблице создаются листы:

- `ответы` — одна строка на участника, сводка;
- `задания` — одна строка на каждое задание каждого участника;
- `стратегии` — самоописания стратегий после блоков;
- `логи` — ошибки, если они возникнут.

Полный JSON сохраняется в Google Drive, ссылка на него попадает в таблицу.

## Как читать JSON

JSON — это полный протокол участника.

Главные разделы:

- `participantId` — анонимный код участника.
- `profile` — анкета участника.
- `tasks` — все сгенерированные задания: правильные ответы, MIDI-ноты, интервалы, аккорды, ступени.
- `trials` — ответы участника по заданиям: что он ответил, верно ли, время реакции, сколько раз нажимал повтор, сколько раз нажимал камертон.
- `blockStrategies` — выбранные стратегии после каждого блока и комментарии.
- `singingReflection` — блок про голос и внутренний слух.
- `motivation` — блок про опыт сольфеджио.
- `summary` в отправленном payload — краткая сводка.

Для обычной работы удобнее смотреть листы `ответы`, `задания`, `стратегии`. JSON нужен как полный архив, если потребуется проверить детали.

## Важные ограничения

- GitHub Pages — статический сайт. Он не хранит данные сам.
- Отправка идёт через Google Apps Script.
- Браузер отправляет запрос в режиме `no-cors`, поэтому сайт не может прочитать ответ сервера. После отправки он показывает страницу благодарности, а исследователю нужно проверить новую строку в Google Sheets.
- Тембры инструментов являются простым синтезом Web Audio API, не настоящими сэмплами.
